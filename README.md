# Hypixel Team Message HUD

Hypixel Team Message HUD is a lightweight Fabric client mod for Hypixel Bed Wars. It mirrors important team-related chat messages to the center action bar so they are easier to notice during a match.

The mod only activates on Hypixel and only after a Bed Wars game has started. It detects your current team from the Minecraft scoreboard, then mirrors chat messages that contain one of your team members' names. The mirrored message keeps the original chat colors where available, with uncolored text shown in gray.

## Features

- Works only on Hypixel Bed Wars
- Detects your team members from the scoreboard
- Shows matching team-related chat messages in the action bar
- Preserves chat text colors in the action bar
- Configurable action bar duration in ticks
- Toggleable from Mod Menu
